EV Market Flask Site

Flask website that embeds the Tableau dashboard and story. Repository: EV-Vehicles-Insights

1. Run it

cd flask_site
pip install -r requirements.txt
python app.py

Open http://127.0.0.1:5000. Press Ctrl+C to stop.

To show your charts after publishing to Tableau Public:

DASHBOARD_URL="https://public.tableau.com/views/<Workbook>/<Sheet>" STORY_URL="https://public.tableau.com/views/<Workbook>/<Sheet>" python app.py

2. Output

3. Source code (app.py)

def ok(u):  # only accept https Tableau Public addresses
    p = urlparse(u.strip())
    return u.strip() if p.scheme == "https" and p.netloc == "public.tableau.com" else ""


def show(**kw):
    return render_template_string(PAGE, gh=GITHUB, kpis=KPIS, **kw)


@app.route("/")
def home():
    return show(tab="home")


@app.route("/dashboard")
def dashboard():
    return show(tab="dashboard", title="Executive Dashboard", url=ok(DASHBOARD_URL), env="DASHBOARD_URL", h=1180)


@app.route("/story")
def story():
    return show(tab="story", title="EV Market Journey", url=ok(STORY_URL), env="STORY_URL", h=1320)


if __name__ == "__main__":
    app.run(debug=True)
