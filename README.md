# ⚡ EV Vehicles Insights
### Electric Vehicle Market Performance Analysis

**An interactive data-analysis project exploring electric vehicle models, manufacturers, battery technologies, vehicle categories, and market regions.**

[![GitHub Repository](https://img.shields.io/badge/GitHub-Repository-181717?logo=github)](https://github.com/nainikasaklecha-commits/EV-Vehicles-Insights)

## 📌 About the Project

**EV Vehicles Insights** explores electric vehicle market data and presents the information through Tableau dashboards, a Tableau Story, and a project website.

The goal is to make the dataset easier to understand by comparing vehicle specifications and identifying patterns across categories, manufacturers, battery types, and regions.

This repository contains dataset files, Tableau workbooks, website HTML files, and the project report.

## 🎯 Project Objectives

- Explore electric vehicle specifications and market categories.
- Compare manufacturers, vehicle models, and regions.
- Examine battery capacity, battery chemistry, and battery cycle life.
- Present data through interactive dashboards and a guided Tableau Story.
- Organize project resources and documentation in one GitHub repository.

## 📈 What the Project Explores

Depending on the fields available in the dataset and workbooks, the analysis explores:

- **Manufacturer Analysis:** Compare manufacturers and vehicle models.
- **Vehicle Categories:** Explore SUVs, sedans, trucks, buses, and other available categories.
- **Battery Technology:** Compare battery types such as LFP, NMC, NCA, Sodium-Ion, and Solid-State where available.
- **Battery Specifications:** Examine battery capacity and cycle-life information.
- **Market Geography:** Explore manufacturing countries and market regions.
- **Model Years:** Understand how vehicle records are distributed across years.

## 🚀 How to View the Project

### View the Website

1. Open the website file from the resource table above.
2. Download the HTML file from GitHub.
3. Open the downloaded file in a web browser.

### View the Tableau Dashboard

1. Download `EV_Market_Performance_Professional-2.twbx`.
2. Open Tableau Desktop.
3. Select **File → Open**.
4. Choose the downloaded `.twbx` file.

### View the Tableau Story

1. Download `EV_Market_Performance_Market_Story.twbx`.
2. Open it in Tableau Desktop.
3. Select the **Story** tab at the bottom of the workbook.
4. Navigate through the story points to explore the analysis.
